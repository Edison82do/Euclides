# MIS CASOS DE PRUEBA  -  Euclides
#
# Cada linea:    pregunta | lo que espero | comentario
#
# ---------------------------------------------------------------------------
# UNIDAD 0.1  ->  cosas separadas por comas.  Repetir un nombre = la MISMA cosa.
#     objeto / uno    una sola entidad
#     varios          dos o mas entidades distintas
#
#     OJO: 0.1 NO decide grupos. Solo dice si hay una cosa o varias.
#
# UNIDAD 0.2 "forman grupo?"  ->  objetos con atributos, separados por ';' o por comas de fuera
#     grupo:color           forman grupo y comparten el color
#     grupo:color,forma     comparten las dos cosas
#     sin_atributo_comun    son varios objetos, pero no comparten nada
#     una_sola_entidad      solo hay una cosa: la pregunta de grupo no aplica
#
# UNIDAD 0.2 "dame el grupo de..."  ->  criterio, luego ':' y la escena
#     tiene:a,c             el grupo son esos
#     no_hay_grupo          ninguno cumple el criterio
#
# En cualquier caso:  no_decidible  -> el sistema dice que no sabe (y hace bien).
# Y '?' en el segundo hueco -> no comprobar nada, solo ver que responde.
#
# Los '#' son comentarios.  Guarda el archivo y el probador lo recarga solo.
# ---------------------------------------------------------------------------

#     dame: <monton> / <palabra>       -> cumplido / no_hay_bastantes / palabra_desconocida
#     tiene: <coleccion> / <palabra>   -> si / no / no_alcanza_la_secuencia / palabra_desconocida

# ===== UNIDAD 2.5  -  el orden de los objetos no importa =====
#     orden: <coleccion>              -> coinciden / no_alcanza_la_secuencia
#     conteo: <recorrido> / <palabras> -> valido / objeto_repetido / palabra_repetida /
#                                         orden_saltado / faltan_objetos_sin_contar / palabras_de_mas
